Why Subword Fragmentation Matters

Critical Data Integrity Defect Discovered
TinyLlama_Sindhi silently deletes native Sindhi letter U+06C1 (HEH GOAL) and corrupts text formatted with Arabic presentation forms, altering up to 24.9% of sentences in FLORES+. FahadQazi_BPE silently drops Latin characters in code-switched text (corrupting 16.2% of Wikipedia sentences). Custom models prevent this via full character coverage and byte fallback.
Linguistic Validation

Targeted 22-Word Morpheme Suite

To verify that vocabulary expansion did not simply memorize high-frequency fragments, all candidate models were evaluated against a targeted linguistic test suite across four orthographic categories:

1. Genitive Postpositions
Words like دنيا جو, خدا جو, and پاڻي جي are cleanly segmented into the base noun and the clitic postposition without corrupting word boundaries.
2. Inflectional Suffixes
Plurals and case inflections such as ڪتابن, شهرن, and توهانڪي are preserved as single intact tokens in 64k models.
3. Digraphs & Implosives
Letters unique to Sindhi (ٻ, ڄ, ڏ, ڳ, ڀ, ٿ, ڇ, ٺ, ڻ) are never fragmented into isolated base letters or raw byte errors.
4. Borrowed Loanwords
Technical terms (ڪمپيوٽر, انٽرنيٽ, اسڪول) remain whole words thanks to the 15% regional language anchor.

Methodology

Training Pipeline & Negative Findings

Trained with the optimal SentencePiece Unigram objective. Standalone script available at training/train_tokenizer.py.

training/train_tokenizer.py 
python training/train_tokenizer.py \
  --corpus data/corpus.txt \
  --vocab_size 64000 \
  --model_prefix models/sindhi_custom_64000 \
  --character_coverage 1.0 \
  --byte_fallback True \
  --split_by_whitespace True
Negative Result: Forced Tokens
Forcing common postpositions (جو, جي, کي) to remain single tokens degraded the training objective (perplexity rose from 9.6 unforced to 14.9 forced at 32k). Unconstrained Unigram naturally discovers superior subword distributions.
Negative Result: Clitic Splitting
Rule-based whitespace separation of supposed clitics proved harmful. Empirical auditing revealed that suspected "fused forms" were simply incidental grapheme sequences inside legitimate root nouns.
Developer Guide

Installation & Quickstart

Load models directly from the Hugging Face Hub or use the local SPMTokenizerAdapter wrapper.

Terminal 
pip install sentencepiece transformers huggingface_hub
Python Script 
from huggingface_hub import hf_hub_download
import sentencepiece as spm

# Download the recommended 64k flagship model from Hugging Face
model_path = hf_hub_download(
    repo_id="alinawazmahar/sindhi-tokenizer", 
    filename="sindhi_custom_64000.model"
)

# Initialize SentencePiece Processor
sp = spm.SentencePieceProcessor(model_file=model_path)

text = "خداوند ڪريم کيس اعليٰ ذهانت سان نوازيو هو"

# Encode to subword tokens & token IDs
tokens = sp.encode(text, out_type=str)
token_ids = sp.encode(text, out_type=int)

print("Subword Tokens:", tokens)
print("Token IDs:", token_ids)
print("Decoded Text:", sp.decode(token_ids))
Important Note on Transformers LlamaTokenizer
Do not use transformers.LlamaTokenizer to load the .model file directly: it can silently fail on custom SentencePiece Unigram models and return a 3-token vocabulary. Always use spm.SentencePieceProcessor or the provided SPMTokenizerAdapter in evaluation/metrics.py.
Applications

Downstream NLP Applications

Optimizing subword fertility directly translates to dramatic efficiency gains in downstream transformer architectures:

Sindhi Large Language Models (LLMs)
By reducing tokens per word from 2.89 (LLaMA) to 1.14, context windows can fit up to 2.5× more text, halving computational pretraining costs.
Machine Translation
Retains proper clitic and postposition boundaries, preventing hallucinations on inflectional affixes.
Sentiment & Text Classification
Preserves emotional valence markers and full grammatical particles without scattering them across fragmented byte tokens.
Named Entity Recognition (NER)
Eliminates the character-drop failure modes observed in competing models that corrupt person and location names.
